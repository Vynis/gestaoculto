Política de Privacidade - Gestão Culto

Última atualização: 14/04/2026

1. Dados coletados

O Gestão Culto coleta dados de cadastro, escalas, ministérios e informações necessárias para o funcionamento da plataforma.

2. Uso dos dados

Os dados são usados para planejamento de cultos, gestão de equipes e comunicação com voluntários.

3. Integração com Google Agenda

Quando o voluntário autoriza, usamos a API do Google Calendar para criar/atualizar/remover eventos das escalas no calendário escolhido.

Essa integração é opcional e pode ser desconectada a qualquer momento pelo próprio voluntário.

4. Compartilhamento

Não vendemos dados pessoais. Compartilhamos dados apenas com provedores necessários para operação técnica, incluindo Google quando houver autorização.

5. Segurança e retenção

Aplicamos controles de acesso e armazenamento seguro. Os dados são mantidos pelo período necessário para fins operacionais e legais.

6. Direitos do usuário

O usuário pode solicitar atualização, correção ou remoção de dados, quando aplicável.

7. Contato
