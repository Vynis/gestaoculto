# Frontend - Gestão de Culto

Aplicação Angular com Nebular focada em operação simples de cultos.

## Pré-requisitos

- Node.js compatível com Angular 16 (>= 16.13)
- npm

## Configuração

Arquivo: `src/environments/environment.ts`

- `apiUrl`: URL da API backend
- `googleClientId`: Client ID OAuth do Google

## Executar

```bash
npm install
npm start
```

Aplicação: `http://localhost:4200`

## Módulos principais

- Login e autenticação
- Dashboard
- Cultos
- Templates de culto
- Cronograma
- Escalas
- Convidados
